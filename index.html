hp game solver

un userscript qui résout les mini-jeux à ta place.

un bouton 🧩 flotte sur la page. tu choisis un jeu, tu appuies, c'est fini. si la partie est déjà terminée, il en relance une.

pas de log. pas d'auto. pas de menu à rallonge.

01 · INSTALLER

trois étapes, pas plus

  1. installe tampermonkey (kiwi ou firefox sur android, n'importe quoi sur desktop)
  2. appuie sur le bouton ci-dessous, tampermonkey propose d'installer
  3. va sur le site du jeu. le 🧩 est en haut à droite
installer le script

à la main : tampermonkey → utilitaires → installer depuis une URL, puis colle le lien.

02 · LES JEUX

ce qu'il sait résoudre

voisinsbacktracking sur la grille : deux cartes voisines partagent un type ou une génération.
coffreà chaque essai, il choisit le code qui coupe le mieux les possibilités restantes.
connexionsil retrouve les groupes tout seul.
cartodleil élimine les candidats jusqu'à tomber sur la bonne carte.
voltorb flipil envoie la grille à un solveur externe et joue les cases sûres.
03 · SOUS LE CAPOT

ce que le script contacte

le site du jeu (avec ta session) et trois domaines :

  • pokeapi.co : données des pokémon
  • api.tcgdex.net : données des cartes
  • voltorbflip.com : solveur de voltorb flip, le seul qui reçoit l'état de ta grille

rien d'autre. pas de tracking, pas de serveur à moi.

04 · ÇA MARCHE PAS

checklist

  • le 🧩 n'apparaît pas : le script est-il activé dans tampermonkey ? recharge la page
  • erreur · HTTP 4xx : tu n'es pas connecté, ou la partie du jour est déjà jouée
  • la page se recharge après la résolution : c'est normal
  • mise à jour : tampermonkey s'en occupe, sinon utilitaires → vérifier les mises à jour

usage perso. si le site change, ça peut casser. c'est la vie.
